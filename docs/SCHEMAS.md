# Shared Contract Schemas

This document defines the frozen Pydantic models and JSON objects that govern communication between components. Any change to these schemas must be approved by the Integration Lead (Member A).

---

## 📌 GoalSchema

Represents the user's initial objective parsed into structured constraints and parameters.

### Pydantic Model

```python
from typing import List, Optional, Dict, Any
from pydantic import BaseModel, Field

class GoalSchema(BaseModel):
    goal_id: str = Field(..., description="Unique transaction ID tracking this agent task run.")
    objective: str = Field(..., description="The main consolidated target of the user query.")
    constraints: List[str] = Field(default_factory=list, description="Extracted rules to restrict browsing (e.g. site blacklists, price limits).")
    metadata: Optional[Dict[str, Any]] = Field(default_factory=dict, description="Additional properties or context tokens parsed from intent.")
```

### JSON Example

```json
{
  "goal_id": "goal_8f2d61a2",
  "objective": "Compare prices of Kindle Paperwhite 16GB",
  "constraints": [
    "Exclude third-party marketplace sellers",
    "Compare exactly Amazon vs Best Buy"
  ],
  "metadata": {
    "currency_preference": "USD"
  }
}
```

## 📌 PlanStep

Represents an atomic task step generated by the planner to be executed by the browser module.

### Pydantic Model

```python
from enum import Enum
from pydantic import BaseModel, Field

class BrowserAction(str, Enum):
    NAVIGATE = "navigate"
    CLICK = "click"
    INPUT = "input"
    SCROLL = "scroll"
    WAIT = "wait"

class PlanStep(BaseModel):
    step_id: int = Field(..., description="Order of execution index (1-indexed).")
    action: BrowserAction = Field(..., description="The browser action to execute.")
    url: Optional[str] = Field(None, description="The target website URL. Required if action is 'navigate'.")
    selector: Optional[str] = Field(None, description="CSS selector for target elements (clicks or inputs).")
    input_value: Optional[str] = Field(None, description="Text string to input. Required if action is 'input'.")
    description: str = Field(..., description="Human-readable explanation of why this step is running.")
```

### JSON Example

```json
{
  "step_id": 1,
  "action": "navigate",
  "url": "https://www.bestbuy.com/site/searchpage?st=Kindle+Paperwhite+16GB",
  "selector": null,
  "input_value": null,
  "description": "Navigate to Best Buy search page for Kindle Paperwhite"
}
```

## 📌 BrowserResult

Represents the raw execution result returned by the browser module (Member B) to the Orchestrator.

### Pydantic Model

```python
from typing import Optional
from pydantic import BaseModel, Field

class BrowserResult(BaseModel):
    step_id: int = Field(..., description="The ID of the plan step this result relates to.")
    status: str = Field(..., description="Execution status: 'success', 'failed', 'timeout'.")
    final_url: str = Field(..., description="The actual loaded URL (handles redirection).")
    raw_html: str = Field(..., description="Raw HTML DOM text captured post-execution.")
    screenshot_path: Optional[str] = Field(None, description="Relative file path of captured viewport image.")
    error_message: Optional[str] = Field(None, description="Detail string of failures if status is not success.")
```

### JSON Example

```json
{
  "step_id": 1,
  "status": "success",
  "final_url": "https://www.bestbuy.com/site/kindle-paperwhite-16gb/6522295.p?skuId=6522295",
  "raw_html": "<html><body><span class='price-block'>$149.99</span></body></html>",
  "screenshot_path": "/artifacts/screenshots/goal_8f2d61a2_step1.webp",
  "error_message": null
}
```

## 📌 ProcessedPage

Represents the sanitized web data output by the processing module (Member C) to the Orchestrator.

### Pydantic Model

```python
from typing import Dict, Any, List
from pydantic import BaseModel, Field

class ProcessedPage(BaseModel):
    step_id: int = Field(..., description="The plan step this processed data belongs to.")
    source_domain: str = Field(..., description="The domain of the source site (e.g., 'bestbuy.com').")
    cleaned_markdown: str = Field(..., description="Sanitized, script-free Markdown representation of page contents.")
    entities: Dict[str, Any] = Field(default_factory=dict, description="Key-value pairs extracted matching the user query (e.g., {'price': '$149.99'}).")
```

### JSON Example

```json
{
  "step_id": 1,
  "source_domain": "bestbuy.com",
  "cleaned_markdown": "### Kindle Paperwhite (Latest Model)\n* Price: $149.99\n* SKU: 6522295\n* In Stock: Yes",
  "entities": {
    "price": "$149.99",
    "model_number": "B09TWDYSVP",
    "stock_status": "In Stock"
  }
}
```

## 📌 FinalReport

Represents the synthesized structure of verified facts compiled in Stage 5, served to the frontend (Member D).

### Pydantic Model

```python
from typing import List, Dict, Any
from pydantic import BaseModel, Field

class SourceCitation(BaseModel):
    domain: str = Field(..., description="The domain citation.")
    url: str = Field(..., description="The full URL reference.")
    screenshot_path: str = Field(..., description="Saved screenshot image path.")

class FinalReport(BaseModel):
    goal_id: str = Field(..., description="The transaction ID this report is delivering on.")
    summary: str = Field(..., description="Consolidated natural language response of findings.")
    comparison_table: List[Dict[str, Any]] = Field(..., description="Structured array representing comparative results.")
    confidence_score: float = Field(..., description="Synthesized confidence value calculated from cross-site source verification.")
    contradictions: List[str] = Field(..., description="List of source assertions that did not match.")
    sources: List[SourceCitation] = Field(..., description="List of citations verifying the data.")
```

### JSON Example

```json
{
  "goal_id": "goal_8f2d61a2",
  "summary": "The Kindle Paperwhite 16GB is currently priced at $149.99 on both Amazon and Best Buy, representing a price match.",
  "comparison_table": [
    {
      "source": "Amazon",
      "price": "$149.99",
      "availability": "In Stock"
    },
    {
      "source": "Best Buy",
      "price": "$149.99",
      "availability": "In Stock"
    }
  ],
  "confidence_score": 1.0,
  "contradictions": [],
  "sources": [
    {
      "domain": "amazon.com",
      "url": "https://www.amazon.com/dp/B09TWDYSVP",
      "screenshot_path": "/artifacts/screenshots/amazon_1.webp"
    },
    {
      "domain": "bestbuy.com",
      "url": "https://www.bestbuy.com/site/kindle/6522295.p",
      "screenshot_path": "/artifacts/screenshots/bestbuy_1.webp"
    }
  ]
}
```
